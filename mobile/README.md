# Мобильное приложение (React Native)

Один код, два режима: **клиент** и **курьер**. Режим выбирается по роли после входа. Приложение исполняется на телефоне; Nginx его не раздаёт. С бэкендом общается только по публичным `/v1/...` и WebSocket `/ws/...` через шлюз Nginx.

## Разработка

```bash
# из корня репозитория: поднять бэкенд
cp .env.example .env && docker compose up --build -d

cd mobile
npm install
npx expo start
```

Адрес бэкенда задаётся в одном месте (конфиг приложения), он зависит от того, где запущено приложение:

| Где запущено | Адрес API |
|---|---|
| Эмулятор Android | `http://10.0.2.2` |
| Симулятор iOS | `http://localhost` |
| Реальный телефон | `http://<IP компьютера в локальной сети>` (телефон и компьютер в одной Wi-Fi сети) |

Готовое приложение собирается в APK/IPA и устанавливается на телефоны; адрес API тогда указывает на боевой сервер.
