# Сервис «Диспетчеризация»

Схема БД: `dispatch` (учётная запись `dispatch_user` видит только её).

Модули:
- `app/modules/assignment/` — M7 Автоназначение
- `app/modules/routing/` — M8 Маршруты и геокодирование

Внутри каждого модуля три слоя: `api.py` → `service.py` → `repository.py`.
Вызывать вниз можно, вверх и «через слой» — нельзя.
